01 / FEATURES

把每个细节
做成体验。

从窗口外壳到网页进程，从快捷菜单到安装向导，LiteBrowser 的每一个部分都经过重新设计。

多标签浏览

标签栏高度固定，标签越多宽度自动压缩；支持拖拽排序、双击 / 中键关闭、恢复关闭的标签页，切换带顺滑动画。

拖拽排序双击关闭恢复标签

垂直标签页

在设置中一键切换为左侧垂直标签栏，页面区域自动让出空间；垂直模式下依然可以拖拽排序。默认关闭。

默认关闭页面自动适配

智能地址栏

识别完整 URL、域名、localhost 与 IP；其余内容交给 Bing、Google、DuckDuckGo 或百度搜索；新标签页不会携带上一页链接。

四种搜索引擎空白起始页

起始页与历史

品牌标志、搜索框和最近历史；历史记录显示网站图标，支持右键删除单条、一键清空。起始页不再放 2048 快捷入口。

favicon右键删除一键清空

书签

地址栏星标收藏，书签栏显示网站真实图标；右键书签可以打开、新标签页打开、复制链接或删除。

书签栏网站图标右键菜单

自绘右键菜单

网页、书签、标签页、历史和下载项统一使用应用内浮层菜单；显示对应快捷键，可用方向键选择、回车执行、Esc 关闭。

Ctrl+CDelF12键盘导航

查找与缩放

页面内查找实时显示匹配数，回车 / Shift+回车跳转；支持 50%–300% 页面缩放，工具栏直接显示当前比例。

实时匹配50%–300%

下载中心

显示 Windows 给文件分配的真实图标、深蓝色进度条和实时速度；支持暂停 / 继续、自定义下载目录，下载中不会误打开文件。

暂停 / 继续文件图标右键菜单

内嵌开发者工具

F12 在窗口右侧停靠显示 DevTools，不再弹出独立窗口；每个标签页独立保留，关闭后页面自动恢复全宽。

右侧停靠按标签保留

主题系统

浅色、深色、跟随系统三种模式，默认跟随系统；切换时同步 prefers-color-scheme，让网站也跟着变色。

浅色深色跟随系统

持久化

保存标签页及其前进 / 后退历史、书签、浏览记录、窗口状态、Cookie 和缓存；重启恢复，覆盖安装也不丢数据。

标签历史Cookie覆盖安装保留

无痕窗口

Ctrl+Shift+N 打开独立无痕窗口，使用临时内存分区，不写入历史、书签或标签页会话；默认搜索引擎为 DuckDuckGo。

独立内存分区DuckDuckGo自动清理

隐私清理

设置中提供「清空 Cookie 和浏览记录」，确认后清理 Cookie、LocalStorage、IndexedDB、Service Worker、缓存和历史记录；书签与下载不受影响。

Cookie缓存浏览记录

2048 小游戏

完全离线的 2048，支持方向键 / WASD、分数和新游戏；从菜单「2048 小游戏」打开，起始页不再显示快捷按钮。

完全离线WASD菜单入口

HTML 文件关联

安装时注册 .html / .htm 文件关联；双击文件通过 file:// 启动，已运行时则通过 second-instance 唤起，并直接作为新标签页打开。

.html / .htm双击打开新标签页

安全隔离

页面启用 sandbox 和 contextIsolation，禁用 nodeIntegration，并施加自定义 CSP；摄像头、麦克风、定位、通知等敏感权限默认拒绝。

sandboxCSP权限默认拒绝

安装与卸载

安装向导显示 EULA 协议页；安装和卸载过程显示详细进度与文件列表；卸载时询问是否保留个人数据，选「否」才清理 AppData。

EULA安装详情保留数据询问

无边框窗口

自绘最小化 / 最大化 / 关闭按钮，关闭按钮悬停为红色；拖动标题栏移动窗口，双击最大化，F11 进入全屏。

自绘窗口红色关闭F11
